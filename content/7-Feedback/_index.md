After participating in the **First Cloud AI Journey** program, I had the opportunity to learn and practice many AWS-related skills through the **Netflop - Movie Streaming Website on AWS** project. This was a valuable experience because I did not only study cloud theory, but also applied it to a realistic system with frontend, backend, database, media storage, video processing, content delivery, and monitoring.

### Overall Evaluation

**1. Learning and working environment**  
The program environment was open and suitable for students who want to learn cloud through hands-on practice. The learning path was divided into clear stages, from fundamentals such as IAM, EC2, S3, and RDS to more advanced services such as MediaConvert, CloudFront, Lambda, and EventBridge. This helped me understand how a web application can be deployed and operated on AWS as a complete architecture.

**2. Support from mentors and community**  
The mentors and FCAJ community provided helpful support during the process of learning AWS services and planning the implementation. When I encountered issues related to architecture, permissions, service configuration, or deployment, I could rely on documentation, community discussion, and step-by-step troubleshooting. I especially appreciated that the program encouraged learners to build, debug, and learn from mistakes instead of only following instructions mechanically.

**3. Relevance to my major and personal direction**  
The Netflop project matched my background in web development, database design, and system deployment. At the same time, it expanded my knowledge of cloud architecture, such as moving media away from the application server, using CDN for video streaming, automating video processing with event-driven architecture, and monitoring the system with CloudWatch. These topics helped me better understand how cloud services support real products.

**4. Learning and skill development opportunities**  
During the project, I improved my ability to read AWS documentation, design architecture, configure infrastructure, troubleshoot deployment issues, write technical reports, and explain system workflows. In particular, implementing the `S3 -> MediaConvert -> CloudFront -> Video Player` pipeline helped me understand media processing and content delivery on the cloud more deeply.

**5. Events and community activities**  
Events such as **FCAJ Community Day - June 2026** helped me keep up with AI and Cloud trends in enterprise environments. Sessions about Voice AI, DevOps AI Agent, Amazon Q, and AI in operations gave me a broader view of how AI can be combined with modern cloud systems.

**6. Areas for improvement**  
Some parts of the program could include more hands-on checklists or examples of common errors so learners can self-check more easily. For services with many configuration details such as IAM, CloudFront, MediaConvert, and Lambda, short troubleshooting guides or flow diagrams would make the learning process smoother and reduce confusion.

### What I Was Most Satisfied With

The most satisfying part was building a practical project rather than only creating isolated AWS resources. Through Netflop, I learned how multiple AWS services work together to solve a real problem: uploading videos, processing HLS, delivering content through CDN, updating episode status automatically, and monitoring the system.

### Suggestions

* Add checklists for each implementation phase so learners can track progress more easily.
* Include common errors for IAM, S3 CORS, CloudFront cache, MediaConvert roles, and Lambda webhooks.
* Add a mid-program architecture review session so learners can receive feedback before finalizing the report.
* Organize more short sessions about AWS production best practices, especially security, cost control, and monitoring.

### Conclusion

Overall, the First Cloud AI Journey program gave me practical knowledge and valuable hands-on experience. After the program, I feel more confident reading AWS documentation, designing cloud architecture, and deploying a multi-component web application on AWS. This is a strong foundation for me to continue developing in Cloud, DevOps, and AI-powered systems.
